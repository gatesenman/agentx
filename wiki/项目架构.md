# 项目架构

## 设计理念

AgentX 的核心设计原则：

1. **IDE 原生格式** — 每个 IDE 使用其官方规定的文件格式，而非统一格式强行适配
2. **零外部依赖** — 每个 IDE 目录自包含，不引用其他 IDE 的文件
3. **能力对齐** — 13 个 IDE 覆盖相同的 15 个规则域，保证一致的智能体行为
4. **直接可用** — 复制到项目即可工作，无需额外配置或安装第三方工具

## 各 IDE 核心文件格式对照

| IDE | 核心规则文件 | 格式要求 |
|-----|------------|---------|
| Claude Code | `CLAUDE.md` | 纯 Markdown，无特殊 frontmatter |
| Cursor | `.cursorrules` + `.cursor/rules/*.mdc` | MDC 格式，需 YAML frontmatter（`description`/`globs`/`alwaysApply`） |
| Windsurf | `.windsurfrules` + `.windsurf/rules/*.md` | Markdown，无 frontmatter |
| Copilot | `AGENTS.md` + `.github/copilot-instructions.md` | 纯 Markdown |
| Codex | `AGENTS.md` | 纯 Markdown |
| Cline | `.clinerules/*.md` | Markdown，按模块分文件 |
| CodeBuddy | `CODEBUDDY.md` + `.codebuddy/rules/*.mdc` | MDC 格式，需 YAML frontmatter（`description`/`globs`） |
| Augment | `.augment/rules/*.md` | Markdown，需 YAML frontmatter（`rule_type: always_apply`） |
| Aider | `.aider.conf.yml` + `CONVENTIONS.md` | YAML 配置 + Markdown 规范文档 |
| Roo Code | `.roorules` + `.roo/rules/*.md` | 全局规则文件 + 分模块 Markdown |
| Amazon Q | `.amazonq/rules/*.md` | Markdown，按模块分文件 |
| Qodo | `AGENTS.md` + `.qodo/agents/*.toml` | Markdown + TOML agent 配置 |
| Devin | `.devin/skills/*/SKILL.md` | Markdown，需 YAML frontmatter（`name`/`description`） |

## 15 个统一规则域

所有 13 个 IDE 均覆盖以下规则域：

| # | 规则域 | 说明 |
|---|--------|------|
| 1 | 身份定义 | 智能体角色和行为基调 |
| 2 | 核心原则 | 持续性、独立性、主动性 |
| 3 | 代码质量 | 最小化修改、遵循现有风格、验证依赖 |
| 4 | 代码注释 | 默认不加注释、不注释 diff |
| 5 | 编码实践 | 优先编辑现有文件、不手改生成文件 |
| 6 | Git 规则 | 不 force push main、不 --no-verify、不 git add . |
| 7 | PR 规则 | 模板、描述规范、CI 验证 |
| 8 | 任务管理 | TODO 列表、进度追踪、多步骤分解 |
| 9 | 仓库设置 | README 优先、先规划再执行 |
| 10 | 工作流程 | 搜索→理解→实现→验证→提交 |
| 11 | 代码审查 | 逐文件审查、关注逻辑和安全 |
| 12 | 冲突解决 | 自动解决简单冲突、复杂冲突上报 |
| 13 | 测试策略 | 不修改测试来通过、发现问题上报 |
| 14 | 密钥协议 | 三选项密钥请求、环境变量引用 |
| 15 | 安全策略 | 仅防御性安全、拒绝恶意代码 |

## 共享资源与 IDE 特定资源

### 跨 IDE 共享的文件（内容相同）

以下文件在 13 个 IDE 目录中内容完全一致：

- `AUTOMATIONS-REFERENCE.md`
- `DECISION-TREES.md`
- `MCP-TOOLS-REFERENCE.md`
- `MEMORY-SYSTEM.md`
- `SKILLS-REFERENCE.md`
- `TROUBLESHOOTING.md`
- `PROMPT-PATTERNS.md`
- `TOOL-CHAINS.md`
- `hooks/` 下所有脚本
- `scripts/` 下所有脚本
- `templates/` 下所有模板
- `workflows/` 下所有 Playbook

### IDE 特定的文件

每个 IDE 目录中只有核心规则文件是 IDE 特定的，格式和内容按各 IDE 官方标准编写。
