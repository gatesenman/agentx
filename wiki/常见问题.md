# 常见问题 (FAQ)

---

## 基础问题

### AgentX 是什么？

AgentX 是一套完整的 AI 编程智能体配置包，覆盖 13 个主流 IDE/AI 工具。它把 AI 智能体的规则、工作流、工具链、安全策略等标准化后，打包成每个 IDE 可直接使用的格式。你只需复制对应 IDE 的文件到你的项目，AI 助手就会按照标准化的行为规则工作。

### 支持哪些 IDE？

| IDE | 官方名称 | 核心文件 |
|-----|---------|---------|
| Claude Code | Anthropic Claude Code | `CLAUDE.md` |
| Cursor | Cursor IDE | `.cursorrules` |
| Windsurf | Windsurf (Cascade) | `.windsurfrules` |
| GitHub Copilot | GitHub Copilot | `AGENTS.md` + `.github/copilot-instructions.md` |
| OpenAI Codex | Codex CLI | `AGENTS.md` |
| Cline | Cline (VS Code 插件) | `.clinerules/` |
| CodeBuddy | 腾讯云 CodeBuddy | `CODEBUDDY.md` + `.codebuddy/rules/` |
| Augment | Augment Code | `.augment/rules/` |
| Aider | Aider | `.aider.conf.yml` + `CONVENTIONS.md` |
| Roo Code | Roo Code | `.roo/rules/` + `.roorules` |
| Amazon Q | Amazon Q Developer | `.amazonq/rules/` |
| Qodo | Qodo (原 Qodo Gen) | `AGENTS.md` + `.qodo/agents/` |
| Devin | Devin 平台 | `.devin/skills/` |

### 是免费的吗？

是的，AgentX 完全开源免费。但使用各 IDE 本身可能需要付费（如 Cursor Pro、Copilot 订阅、Devin 平台等）。

### 需要什么前置条件？

- 一个 Git 仓库（已 `git init`）
- 至少安装了一个上述 IDE/AI 工具
- （可选）Node.js / Python 等运行环境（用于 lint 和 typecheck）

## 安装问题

### 怎么安装？

```bash
# 1. 克隆 AgentX
git clone https://github.com/gaosichun888/agentx.git

# 2. 复制对应 IDE 的文件（以 Claude Code 为例）
cp agentx/claude-code/CLAUDE.md /你的项目/
cp -r agentx/claude-code/hooks /你的项目/

# 3. 安装 Git Hooks
cd /你的项目 && bash hooks/install-hooks.sh
```

详细步骤见 [快速开始](快速开始.md)。

### 可以同时安装多个 IDE 的配置吗？

可以。各 IDE 的规则文件互不冲突：
- `CLAUDE.md` 只被 Claude Code 读取
- `.cursorrules` 只被 Cursor 读取
- `.windsurfrules` 只被 Windsurf 读取
- 以此类推

你可以同时安装所有 IDE 的配置，不会互相干扰。

### install-hooks.sh 报权限错误

```bash
# 添加执行权限
chmod +x hooks/install-hooks.sh
# 再运行
bash hooks/install-hooks.sh
```

### hooks 安装后不生效

检查以下几点：

```bash
# 1. 确认文件存在
ls -la .git/hooks/pre-commit

# 2. 确认有执行权限
stat .git/hooks/pre-commit | grep -i access

# 3. 确认文件有正确的 shebang
head -1 .git/hooks/pre-commit
# 应该显示: #!/bin/bash

# 4. 手动测试
bash .git/hooks/pre-commit
```

### Windows 下 hooks 不工作

确保使用 Git Bash 而非 PowerShell 运行安装脚本：

```bash
# 在 Git Bash 中运行
bash hooks/install-hooks.sh
```

### 怎么验证规则是否生效？

对 AI 助手说："请告诉我你当前的工作原则是什么？" 或 "你的 Git 提交规则是什么？"

如果回答包含 Conventional Commits、密钥检测等内容，说明规则已加载。

### 怎么自定义规则？

直接编辑对应的规则文件即可。详见 [规则系统](规则系统.md)。

建议：
- 保留核心安全规则（密钥检测、禁止 force push 等）
- 根据项目需求调整代码风格规则
- 添加项目特定的工作流步骤

### 工作流文件（workflows/）是必须的吗？

不是。工作流文件是参考文档，帮助 AI 智能体理解如何执行常见任务。如果你只需要基本的规则约束，只复制核心规则文件即可。

### hooks/scripts/templates 是必须的吗？

不是。这些是辅助工具：
- **hooks** — 推荐安装，自动化质量检查
- **scripts** — 可选，便利脚本
- **templates** — 可选，配置模板参考

## 兼容性问题

### 和项目已有的 .cursorrules 冲突怎么办？

AgentX 的规则会覆盖已有文件。建议：

1. 先备份现有规则：`cp .cursorrules .cursorrules.backup`
2. 安装 AgentX 规则
3. 将原有规则中的项目特定内容合并到 AgentX 规则中

### 和 pre-commit 框架（pre-commit.com）冲突吗？

不冲突。AgentX 的 hooks 是独立的 bash 脚本。如果你使用 pre-commit 框架：

1. 可以把 AgentX 的检查作为额外步骤添加到 `.pre-commit-config.yaml`
2. 或者只用 AgentX 的 hooks，不用 pre-commit 框架
3. 两者同时使用时，`.git/hooks/pre-commit` 会优先执行 pre-commit 框架的入口脚本

### 支持 Monorepo 吗？

支持。可以在 Monorepo 的根目录放置全局规则，各子包放置特定规则：

```
monorepo/
├── CLAUDE.md              # 全局规则
├── .cursorrules           # 全局规则
├── packages/
│   ├── web/
│   │   └── .cursor/rules/web-rules.mdc  # web 专用规则
│   └── api/
│       └── .cursor/rules/api-rules.mdc  # api 专用规则
```

## 升级和维护

### 怎么更新到最新版本？

```bash
cd agentx
git pull origin main
# 重新复制需要的文件到你的项目
```

### 会破坏我现有的代码吗？

不会。AgentX 只添加配置文件和脚本，不修改你的源代码。唯一可能的影响是 Git hooks 会在提交时做检查——如果检查不通过会阻止提交，但不会修改代码。
