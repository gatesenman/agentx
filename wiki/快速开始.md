# 快速开始

本指南帮助你在 5 分钟内将 AgentX 配置安装到你的项目中。

---

## 第一步：克隆 AgentX 仓库

```bash
git clone https://github.com/gaosichun888/agentx.git
cd agentx
```

## 第三步：安装 Git Hooks

```bash
cd /你的项目
bash hooks/install-hooks.sh
```

安装脚本会：
1. 检测是否在 Git 仓库中
2. 自动备份已有的 hooks（添加 `.backup` 后缀）
3. 复制 `pre-commit`、`commit-msg`、`pre-push` 到 `.git/hooks/`
4. 设置可执行权限

### 验证安装

```bash
# 检查 hooks 是否安装成功
ls -la .git/hooks/pre-commit .git/hooks/commit-msg .git/hooks/pre-push

# 测试 pre-commit hook（不会实际提交）
echo "test" > /tmp/test-file
git add /tmp/test-file 2>/dev/null || echo "hook 已激活"

# 测试 commit-msg hook（应拒绝不规范的消息）
echo "bad message" > /tmp/test-msg
.git/hooks/commit-msg /tmp/test-msg && echo "未拦截" || echo "已拦截，hook 工作正常"

# 测试规范的 commit 消息（应通过）
echo "feat: 添加新功能" > /tmp/test-msg
.git/hooks/commit-msg /tmp/test-msg && echo "通过，hook 工作正常" || echo "拦截"
```

## 第四步：验证 IDE 加载规则

### Claude Code

1. 打开 Claude Code（`claude` CLI 或 VS Code 扩展）
2. 输入 `/rules` 或 `/context` 查看是否加载了 `CLAUDE.md`
3. 提问 "你的工作原则是什么？" — 应回答包含核心规则内容

### Cursor

1. 打开 Cursor IDE
2. 进入 Settings → Rules → Project Rules
3. 确认 `.cursorrules` 和 `.cursor/rules/` 已显示
4. 打开 Composer，规则会自动注入

### Windsurf

1. 打开 Windsurf IDE
2. 检查 `.windsurfrules` 是否被识别
3. 使用 Cascade，规则会自动生效

### GitHub Copilot

1. 在 VS Code 中使用 Copilot Chat
2. 检查 `.github/copilot-instructions.md` 是否在指令中
3. 对于 Copilot Workspace / Codex，`AGENTS.md` 自动加载

### Aider

```bash
# 在项目目录运行 aider
cd /你的项目
aider

# aider 会自动读取 .aider.conf.yml 和 CONVENTIONS.md
# 输入 /settings 查看配置
```

### Devin

1. 推送 `.devin/skills/` 到远程仓库
2. 在 Devin 平台创建会话，选择对应仓库
3. 技能会自动加载，可在会话中使用 `skill list` 查看

## 一键安装脚本（所有文件）

如果你想一次安装所有参考文档、hooks、脚本、模板和工作流：

```bash
#!/bin/bash
# one-click-install.sh
# 用法: bash one-click-install.sh <IDE名称> <目标项目路径>

IDE=$1
TARGET=$2

if [ -z "$IDE" ] || [ -z "$TARGET" ]; then
    echo "用法: bash one-click-install.sh <IDE名称> <目标项目路径>"
    echo "IDE 名称: claude-code, cursor, windsurf, copilot, codex, cline,"
    echo "          codebuddy, augment, aider, roo-code, amazon-q, qodo, devin"
    exit 1
fi

if [ ! -d "$IDE" ]; then
    echo "错误: IDE 目录 '$IDE' 不存在"
    exit 1
fi

echo "正在将 $IDE 配置安装到 $TARGET ..."

# 复制所有文件（排除 README.md）
find "$IDE" -type f ! -name "README.md" | while read f; do
    relative="${f#$IDE/}"
    target_dir="$TARGET/$(dirname "$relative")"
    mkdir -p "$target_dir"
    cp "$f" "$TARGET/$relative"
done

echo "安装完成！共复制 $(find "$IDE" -type f ! -name "README.md" | wc -l) 个文件"
echo ""
echo "下一步: cd $TARGET && bash hooks/install-hooks.sh"
```

## 多 IDE 并行使用

如果你的团队使用多个 IDE，可以同时安装多个配置：

```bash
# 同时安装 Claude Code + Cursor + Copilot
bash one-click-install.sh claude-code /你的项目
bash one-click-install.sh cursor /你的项目
bash one-click-install.sh copilot /你的项目
# hooks 只需安装一次
cd /你的项目 && bash hooks/install-hooks.sh
```

各 IDE 的规则文件互不冲突，可以安全地共存于同一个项目中。
