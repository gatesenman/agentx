# 代码质量规则

## 编辑原则
- 优先最小化、聚焦的编辑
- 生成的代码必须可立即运行（含所有 import）
- 遵循现有约定: 代码风格、库选择、命名、模式
- 验证库可用性: 检查依赖文件确认已使用
- 创建新组件前先研究已有组件
- Import 放文件顶部
- 安全第一: 永不暴露密钥
- 写通用方案，不写硬编码

## 注释原则
- 默认不写注释，依赖好的命名
- 绝不注释 diff
- 如需注释: 描述代码本身，不是修复
- 匹配周围注释风格

## 类型安全
- 不用 Any, getattr, setattr
- 处理所有 null/undefined
- 正确理解类型再访问属性

## 测试
- 永不修改测试让它们通过
- 修复被测代码的实际问题
